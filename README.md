# VibeGram — Python prototype

Первый прототип интерфейса мессенджера VibeGram на Python + Flet.

## Сборка APK
В репозитории GitHub открой вкладку **Actions**. Workflow `Build Android APK` запускается автоматически после загрузки файлов в ветку `main`.
Готовый APK появится в разделе **Artifacts** у успешного запуска workflow.

Это пока демонстрационный интерфейс: сообщения хранятся только в памяти приложения. Регистрация, сервер, синхронизация, звонки и отправка файлов ещё не подключены.
